# Hướng dẫn sử dụng:
# 1. Mở file hosts với quyền Administrator:
#    - Windows: C:\Windows\System32\drivers\etc\hosts
#    - Hoặc chạy Notepad as Administrator và mở file hosts
# 
# 2. Copy toàn bộ nội dung dưới đây và paste vào cuối file hosts
# 
# 3. Lưu file và kiểm tra lại
# 
# 4. Sau khi thêm, bạn có thể truy cập các services bằng domain name:
#    - http://kafka.studymate.local:8080
#    - http://vault.studymate.local:8200
#    - etc.
